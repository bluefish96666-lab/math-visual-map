# 高中数学图形化知识地图

按人教 A 版 2019 高中数学教材（必修第一、二册，选择性必修第一、二、三册）整理的图形化学习网页：5 册 18 章，每章一张示意图，每节有要点和公式，标出"高考怎么考"和易错点，可以勾选记录掌握进度。

## 使用

- 在线：开启 GitHub Pages 后访问仓库的 Pages 网址。
- 本地：双击 `index.html`，不需要联网或安装软件。

## 交互实验

每个实验都有"高考题型"一键预设，右侧面板给出随拖动实时更新的解题过程。坐标系可以拖动空白处平移、滚轮缩放、双击复位。

函数与导数：

- `labs/function-graph.html`：函数图像变换 y = A·f(ω(x − h)) + k，f(|x|) 与 |f(x)| 翻折，反函数；自动判断定义域、奇偶性、单调区间、零点、渐近线和周期。
- `labs/derivative.html`：割线逼近切线，f 与 f′ 图像上下对照，"在点"与"过点"的切线条数，三次函数图像分类，含参单调性分类讨论。
- `labs/zeros.html`：零点个数与分离参数，拖动水平线 y = a，按极值和端点极限列出参数范围表（开闭区间），并对照原方程的图像。
- `labs/compare.html`：比较大小三种思路：把几个数看成同一 x 处的函数值（含 2022 新高考Ⅰ、2021 乙卷，可放大到 x₀ 附近），构造 ln x / x 比较 aᵇ 与 bᵃ，切线放缩 eˣ ≥ x + 1、ln x ≤ x − 1 等并画出差函数。

三角与向量：

- `labs/trig.html`：y = A sin(ωx + φ) + B 与单位圆联动，"先平移"和"先伸缩"两种顺序分步演示，对称轴、对称中心、五点法，由图求解析式小测验。
- `labs/omega.html`：ω 的取值范围。整体换元 t = ωx + φ，上图看 f(x)、下图看 sin t 和 T = ωm + φ 的允许范围；条件可选零点、极值点、最值点个数或单调，两个条件取交集，精确给出 ω 的区间（分数形式）。
- `labs/vector.html`：加减法与投影向量，平面向量基本定理与等和线，极化恒等式求数量积最值。
- `labs/triangle.html`：正弦定理与外接圆，两边一对角的解的个数，定边定角求面积和周长最值（含锐角三角形范围）。

几何：

- `labs/solid.html`：可旋转的正方体、四棱锥、正四棱锥、直三棱柱；选点求异面直线角、线面角、二面角、点面距，显示法向量求解过程和截面形状，棱上动点 λ 可调。
- `labs/conic.html`：圆、椭圆、双曲线、抛物线的定义与焦点三角形；拖动直线看联立、判别式、韦达定理、弦长、中点弦（点差法）、过焦点的弦。
- `labs/sphere.html`：外接球与内切球。长方体、墙角（三条棱两两垂直）、正四面体、直三棱柱、侧棱垂直底面的三棱锥、正棱锥六种模型，可旋转，画出球心、底面外心和 R² = r² + d² 的直角三角形；内切球用 r = 3V/S。
- `labs/fixed-point.html`：圆锥曲线定点定值。椭圆、双曲线、抛物线上过定点 A 作两条弦，条件可选垂直、斜率积、斜率和、斜率互为相反数；转动弦时自动检测动直线过的定点、定斜率、定距离等不变量，并给出 x = my + t 的韦达定理推导。

数列：

- `labs/sequence.html`：等差数列 Sₙ 最值，等比数列求和与 q = 1 陷阱，aₙ₊₁ = paₙ + q 的蛛网图与不动点。

概率统计：

- `labs/probability.html`：二项分布、超几何分布、两者对比，正态分布与 3σ 原则；可模拟 1000 次试验看频率逼近概率。
- `labs/regression.html`：拖动、增删散点，最小二乘回归直线、样本中心、相关系数 r、残差与 R²，可放一条自己的直线比较残差平方和。
- `labs/conditional.html`：条件概率、全概率公式与贝叶斯公式的面积图和树状图（2～3 个原因），独立性判断；2×2 列联表的 χ² 独立性检验，χ² 分布曲线上标出临界值与拒绝域。

适合电脑和平板，不针对手机排版。实验共用 `assets/lab.css`、`assets/lab.js` 和坐标系工具 `assets/plane.js`；教材目录与考点数据在 `assets/curriculum.js`，章节示意图在 `assets/figures.js`。
