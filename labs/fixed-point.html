常用结论

拖一拖，验证这些结论
  • 椭圆 x²/a² + y²/b² = 1 的顶点 A(a, 0)，AP ⊥ AQ ⇒ PQ 过定点 (a(a² − b²)/(a² + b²), 0)。
  • 抛物线 y² = 2px 上一点 A(x₀, y₀)，AP ⊥ AQ ⇒ PQ 过定点 (x₀ + 2p, −y₀)；A 为原点时定点是 (2p, 0)。
  • A 在曲线上且 k₁ + k₂ = 0 ⇒ PQ 斜率为定值：椭圆 b²x₀/(a²y₀)，抛物线 −p/y₀。
  • 椭圆 OP ⊥ OQ ⇒ 1/|OP|² + 1/|OQ|² = 1/a² + 1/b²，O 到 PQ 的距离为定值 ab/√(a² + b²)。
  • 焦点弦：抛物线 1/|FP| + 1/|FQ| = 2/p；椭圆 1/|FP| + 1/|FQ| = 2a/b²。
  • 做题顺序：先用特殊位置（如 PQ ⊥ x 轴）猜出定点或定值，再设直线 x = my + t 联立，用韦达定理证明。
