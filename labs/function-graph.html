常用结论

拖一拖，验证这些结论
  • f(x + a) = f(a − x)（或 f(x) = f(2a − x)）⇔ 图像关于直线 x = a 对称；f(a + x) + f(a − x) = 2b ⇔ 关于点 (a, b) 对称。
  • f(|x|) 一定是偶函数；|f(x)| 的图像在 x 轴上方或在 x 轴上。
  • 奇函数在对称区间上单调性相同，偶函数相反。
  • y = aˣ 与 y = log_a x 互为反函数，图像关于 y = x 对称；y = log₂(−x) 与 y = log₂x 关于 y 轴对称。
  • 对勾函数 y = x + a/x（a > 0）：在 (0, √a) 递减、(√a, +∞) 递增，x > 0 时最小值 2√a。
