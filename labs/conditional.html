常用结论

拖一拖，验证这些结论
  • 条件概率 P(B|A) = P(AB)/P(A)：把样本空间缩小到 A 里面看 B 占多少。乘法公式 P(AB) = P(A)P(B|A)。
  • 全概率公式：A₁、A₂、…… 两两互斥且并起来是全体，P(B) = Σ P(Aᵢ)P(B|Aᵢ)。"由因求果"。
  • 贝叶斯公式：P(Aᵢ|B) = P(Aᵢ)P(B|Aᵢ) / P(B)。"由果溯因"，分母就是全概率。
  • A、B 独立 ⇔ P(B|A) = P(B|Ā) = P(B)：面积图里各列的分界线对齐。
  • χ² = n(ad − bc)² / [(a + b)(c + d)(a + c)(b + d)]；χ² ≥ x_α 时推断两变量不独立（有关联），犯错概率不超过 α。
  • 临界值：α = 0.1 → 2.706，0.05 → 3.841，0.01 → 6.635，0.005 → 7.879，0.001 → 10.828。
