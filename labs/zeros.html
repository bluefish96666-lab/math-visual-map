拖一拖，验证这些结论
  • 分离参数前要确认变形是等价的：两边同除以 x 时要单独检验 x = 0 是不是根。
  • "有两个零点"的答案常是开区间，端点对应"相切"（一个根）或"取不到的极限值"。
  • 常见图像：xeˣ 最小值 −1/e；ln x / x 最大值 1/e；eˣ/x 在 x > 0 的最小值 e；x ln x 最小值 −1/e。
  • 极限的写法：x → 0⁺ 时 x ln x → 0，x → +∞ 时 ln x / x → 0、x²/eˣ → 0（指数增长快于幂函数，幂函数快于对数）。
  • 不能分离参数（或分离后的函数太复杂）时，改为直接讨论原函数的单调性和极值。
