拖一拖，验证这些结论
  • 比大小先找中间量 0、1（如 log₂0.3 < 0 < 0.3² < 1 < 2⁰·³），再看单调性。
  • 几个数"长得像"时，把它们看成同一个函数在同一点的值，或者不同函数在同一个 x 处的值，再构造差函数求导。
  • f(x) = ln x / x 在 (0, e) 增、(e, +∞) 减，最大值 1/e；ab 与 ba 比较 ⇔ ln a / a 与 ln b / b 比较。2⁴ = 4²。
  • 切线放缩：eˣ ≥ x + 1，ln x ≤ x − 1，eˣ ≥ ex，ln x ≤ x/e，ln x ≥ 1 − 1/x，等号都在切点处成立。
  • x 很小时：eˣ − 1 ≈ x ≈ ln(1 + x) ≈ sin x，需要更精细的比较时，构造函数 h(x) = 两式之差，看 h(0) = 0 与 h′ 的符号。
