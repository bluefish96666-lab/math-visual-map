常用结论

拖一拖，验证这些结论
  • 对称轴过最高点或最低点：令 ωx + φ = π/2 + kπ；对称中心是零点：令 ωx + φ = kπ，中心纵坐标是 B。
  • 相邻两条对称轴相距 T/2，对称轴与相邻对称中心相距 T/4。
  • 求单调增区间：令 −π/2 + 2kπ ≤ ωx + φ ≤ π/2 + 2kπ（ω > 0 时）。ω < 0 要先用诱导公式化成正的。
  • 由图求 φ：代入最高点 ωx₀ + φ = π/2 + 2kπ，再结合 |φ| 的范围取值；代零点容易分不清是"上升零点"还是"下降零点"。
  • y = sin(ωx + φ) 是奇函数 ⇔ φ = kπ；是偶函数 ⇔ φ = π/2 + kπ。
