常用结论

拖一拖，验证这些结论
  • 割线斜率 [f(x₀ + Δx) − f(x₀)]/Δx 在 Δx → 0 时的极限就是切线斜率 f′(x₀)。
  • "在点 P 处"：P 就是切点，k = f′(x₀)。"过点 Q"：Q 不一定是切点，要设切点 (t, f(t))，由 f(t) + f′(t)(x_Q − t) = y_Q 解 t，可能有多条。
  • f′(x₀) = 0 只是 x₀ 为极值点的必要条件：x³ 在 0 处导数为 0，但不是极值点。
  • 三次函数 f′ = 3ax² + 2bx + c：Δ ≤ 0 时单调，Δ > 0 时有两个极值点；图像关于点 (−b/(3a), f(−b/(3a))) 中心对称。
  • 含参讨论单调性：先求导，再按 f′ 的零点"有没有、在不在定义域内、谁大谁小"分类。
  • 常用切线放缩：eˣ ≥ x + 1，ln x ≤ x − 1，都在 x = 0（或 x = 1）处取等号。
