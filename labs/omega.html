解题套路
  • ω > 0 时，x ∈ (0, m) ⇒ t = ωx + φ ∈ (φ, ωm + φ)，左端点 φ 固定，只有右端点 T = ωm + φ 随 ω 移动。
  • sin t 的零点 t = kπ，最大值点 t = π/2 + 2kπ，最小值点 t = 3π/2 + 2kπ，极值点（对称轴）t = π/2 + kπ。
  • "恰有 n 个"：T 落在第 n 个与第 n + 1 个特征点之间；端点取不取等号由区间开闭决定（闭区间端点上的零点也算）。
  • 单调：(φ, T) 内不含极值点，即 T 不超过 φ 右侧第一个极值点；还要看 φ 处在增区间还是减区间。
  • cos ωx 型先化成 sin：cos ωx = sin(ωx + π/2)。
