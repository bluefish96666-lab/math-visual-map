常用结论

拖一拖，验证这些结论
  • 大边对大角：a > b ⇔ A > B ⇔ sin A > sin B。
  • a² < b² + c² ⇔ A 为锐角；判断三角形形状只需看最大边。
  • 面积 S = ½ab·sin C = abc/(4R) = ½r(a + b + c)，r 是内切圆半径。
  • a、A 固定时，A 点在一段圆弧上运动；b = c 时面积和周长都最大：S_max = a²/(4tan(A/2))，(b + c)_max = a/sin(A/2)。
  • 锐角三角形求范围：先由 B、C 都是锐角定出 B 的范围，再把目标化成关于 B 的三角函数。
