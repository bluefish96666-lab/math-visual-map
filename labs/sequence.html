常用结论

拖一拖，验证这些结论
  • 等差数列 Sₙ = (d/2)n² + (a₁ − d/2)n，是过原点的"二次函数取整数点"；d < 0 时开口向下，有最大值。
  • 等差 Sₙ 最大的 n：找最后一个非负项（aₙ ≥ 0 且 aₙ₊₁ ≤ 0）。若某项恰为 0，相邻两个 n 的 Sₙ 相等，都是最大值。
  • 等比数列求和必须先看 q 是否等于 1；|q| < 1 时 Sₙ → a₁/(1 − q)。
  • aₙ₊₁ = paₙ + q（p ≠ 1）：设不动点 x = q/(1 − p)，则 {aₙ − x} 是公比为 p 的等比数列。
  • 蛛网图：从 aₙ 竖直走到直线 y = px + q 得 aₙ₊₁，再水平走到 y = x 回到横轴位置。|p| < 1 时收敛到不动点。
