常用结论

拖一拖，验证这些结论
  • 长方体：2R = √(a² + b² + c²)；正方体棱长 a：外接球 R = √3a/2，内切球 r = a/2，棱切球 √2a/2。
  • 墙角模型（三条棱两两垂直）：补成长方体，2R = √(a² + b² + c²)。
  • 正四面体棱长 a：R = √6a/4，r = √6a/12，R = 3r；球心是高的四等分点。
  • 直棱柱、侧棱垂直底面的锥：R² = r² + (h/2)²，r 是底面外接圆半径（r = 对边/(2sin 对角)）。
  • 正棱锥：球心在高上，(h − R)² + r² = R²，R = (h² + r²)/(2h)；h < r 时球心在底面下方。
  • 内切球：r = 3V / S表（等体积法）。
